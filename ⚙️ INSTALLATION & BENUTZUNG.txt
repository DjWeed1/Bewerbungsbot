⚙️ INSTALLATION & BENUTZUNG
1️⃣ Voraussetzungen

Python 3.11 ist bereits installiert ✅

2️⃣ Erforderliche Pakete installieren oder das ausführen setup_bewerbungsbot.py  mit py setup_bewerbungsbot.py in cmd/power Shell/etc.
Gehe auf JOB_PORTAL_URL=https://jobroom.ams.or.at/jobsuche/FreieSuche.jsp suche dir deine Angebote du musst nur die Stellenanzeigen durch gehen und alles was eine E-Mail Adresse hat unt dir gefällt, wird mit Rechtsklick speichern unter Bewerbungsbot/Anzeigen gespeichert, wenn du das 100 x machst und danach denn bot startest wird er alle emailadressen raussuchen und überall eine Bewerbung hin schicken mit Lebenslauf/Zeugnisse/etc.
Öffne PowerShell oder CMD und gib ein:

pip install pandas beautifulsoup4 chardet python-dotenv colorama openpyxl

3️⃣ Ordnerstruktur anlegen

Beispiel:

C:\Users\User\Documents\Bewerbungsbot\
│
├── Bewerbungsbot_Template.py
├── .env
├── lebenslauf.pdf
├── anzeigen\
└── Bewerbungen.xlsx

4️⃣ .env Datei anlegen

Erstelle in deinem Hauptordner (.env) mit folgendem Inhalt:

EMAIL_USER=dein.email@gmail.com
EMAIL_PASS=deinAppPasswort
SEND_REAL_EMAILS=True


Tipp: Bei Gmail brauchst du ein App-Passwort (nicht dein normales Passwort!)
https://myaccount.google.com/apppasswords

5️⃣ Start
python Bewerbungsbot_Template.py


Wenn du nur testen willst, setze in der .env:
SEND_REAL_EMAILS=False

6️⃣ Anpassung

Ersetze im Code:

*NAME* → dein Name

*ORDNER_HTML*, *EXCEL_FILE*, *CV_FILE*, *ENV_PATH* → deine Pfade
